## Open-source software

feega runs on open-source software. The main projects:

| Project | Use | License |
|---|---|---|
| [Svelte](https://svelte.dev/) and [SvelteKit](https://svelte.dev/docs/kit) | the application | MIT |
| [Svelte Flow](https://svelteflow.dev/) (xyflow) | the canvas | MIT |
| [Bits UI](https://bits-ui.com/) | menus, dialogs, tooltips | MIT |
| [Tailwind CSS](https://tailwindcss.com/) | styling | MIT |
| [marked](https://marked.js.org/) | rendering Markdown | MIT |
| [svelte-i18n](https://github.com/kaisermann/svelte-i18n) | translations | MIT |
| [Supabase JS](https://github.com/supabase/supabase-js) | data and storage client | MIT |
| [AI SDK](https://ai-sdk.dev/) | calling AI models | Apache 2.0 |

The complete list of dependencies and their licenses ships with the source code.

## AI models

Text, images and video are generated by third-party models reached through
[OpenRouter](https://openrouter.ai/) and the providers named in each model's menu entry. Each
model is subject to its provider's terms.
