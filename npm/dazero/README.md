# dazero

> Infinite canvas of real terminals for orchestrating AI agents in parallel.

Install and run:

```bash
npx dazero start
```

Or install globally:

```bash
npm i -g dazero
dazero start
```

The browser opens `http://localhost:7000` automatically. You get a real interactive
terminal (PTY) in the browser — the foundation for the multi-agent canvas coming in M2+.

**More info:** [github.com/andreabuttarelli/dazero](https://github.com/andreabuttarelli/dazero)
